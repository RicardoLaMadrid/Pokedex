# Instalación

1. Clona el repositorio:
    ```bash
    git clone https://github.com/RicardoLaMadrid/Pokedex
    cd POKEDEX1.0
    ```

2. Crea un entorno virtual 
  
  python -m venv env 
  source env/bin/activate

3. Instala las dependencias:

    pip install -r requirements.txt
   

4. Ejecuta la aplicación:
 
    python app.py
